# Tutorials

These tutorials cover the **domain layer**. For how the recipe engine and LMDB
builds work, see the [DataCooker docs](https://CSSB-SNU.github.io/DataCooker/).

- [OpenFold3 distillation ingest](tutorials/openfold-distillation.md) — build
  MSA, structure (CIFMol), and template LMDBs from the OpenFold3 distillation
  datasets (long monomers, short monomers, RNA) with one reader/transform/writer
  set per data type.
